以下内容通过 [NeoDB](https://neodb.social/users/NeuroRead/) 管理。目前以静态示例展示；接入真实数据需要导出 NeoDB 数据文件或申请 API Token。

如果要自动展示你标记的影视作品，有两种方式：

1. **导出 JSON 数据** — 在 NeoDB 设置中导出，然后放入 Hugo 的 `data/` 目录。只需要导出一次，想更新时再导一次。
2. **申请 NeoDB API Token** — 在 [NeoDB Developer](https://neodb.social/developer/) 创建应用获取 Token，我可以做成前端实时拉数据（类似追番页的方案）。
